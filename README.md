# Bruno Galati — Art, Code & Intelligence

A scroll-driven portfolio piece: a walk through art history (Lascaux, Brunelleschi, De Stijl, Op Art, Suprematism, Futurism, Pop, Rothko) and a reflection on craft and AI.

Built with React 19, Vite and Framer Motion. Deployed to https://brunobruno.github.io via GitHub Actions on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # outputs dist/
```

Copy and timeline content live in `src/data/content.js`.
